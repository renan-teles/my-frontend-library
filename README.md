# 🚀 My Frontend Library

Uma biblioteca frontend própria, desenvolvida em JavaScript puro, com foco em **simplicidade, reutilização e controle sobre a aplicação**.

O projeto nasceu como uma forma de estudar, na prática, conceitos presentes em frameworks modernos como React, Angular e Vue, mas também possui um objetivo prático: **servir como uma alternativa própria para projetos pessoais de pequeno e médio porte nos quais o uso de um framework completo pode ser desnecessário**.

Este projeto não tem como objetivo competir com frameworks ou bibliotecas consolidadas como React, Angular ou Vue.

A proposta aqui é diferente: construir uma ferramenta **menor, própria e adequada às minhas necessidades**, enquanto utilizo o próprio desenvolvimento dela como oportunidade para aprofundar meus conhecimentos em JavaScript e arquitetura frontend.

> ⚠️ Este projeto está em estágio inicial de desenvolvimento e ainda não deve ser considerado estável ou recomendado para aplicações em produção.

## 🎯 Objetivos

O projeto possui dois objetivos principais:

### 📚 Aprendizado e experimentação

Implementar manualmente conceitos comuns do desenvolvimento frontend moderno para compreender melhor seus fundamentos e as decisões envolvidas na construção de bibliotecas e frameworks.

Entre esses conceitos estão:

- 🧩 Componentização
- 🖥️ Renderização de elementos DOM
- 🔄 Gerenciamento de estado
- 🏗️ Criação de layouts reutilizáveis
- 📦 Organização modular de código

### 🛠️ Utilização em projetos pessoais

Além do propósito educacional, o projeto também pretende evoluir para uma biblioteca pequena e prática para meus próprios projetos.

A ideia é ter uma alternativa intermediária entre:

- 📝 desenvolver uma aplicação completamente do zero, repetindo diversas soluções;
- ⚙️ utilizar frameworks maiores e mais completos quando eles não forem necessários.

Para projetos pessoais pequenos e médios, nos quais não exista a necessidade de todo o ecossistema e da complexidade de um framework completo, esta biblioteca poderá fornecer uma estrutura básica e reutilizável para desenvolvimento frontend.

Dessa forma, a biblioteca não existe apenas para **estudar como frameworks e bibliotecas funcionam**, mas também para **ser utilizada como uma ferramenta própria de desenvolvimento**.

## 🧭 Filosofia

A proposta é manter a biblioteca relativamente pequena e compreensível.

Em vez de tentar reproduzir todas as funcionalidades e abstrações encontradas em frameworks consolidados, o objetivo é oferecer apenas recursos que sejam realmente úteis para os projetos aos quais ela se destina.

Alguns princípios importantes são:

- ✨ **Simplicidade:** evitar abstrações desnecessariamente complexas.
- ♻️ **Reutilização:** reduzir código repetitivo entre projetos.
- 🎛️ **Controle:** manter o funcionamento da aplicação próximo ao JavaScript e ao DOM.
- 🔧 **Flexibilidade:** permitir que cada projeto utilize apenas os recursos necessários.
- 💡 **Compreensibilidade:** manter a implementação suficientemente simples para que seu funcionamento possa ser estudado e entendido.
- 🕊️ **Independência:** reduzir a necessidade de utilizar frameworks externos em projetos pessoais que não necessitem deles.

## 🚧 Status do projeto

Atualmente, o projeto está em desenvolvimento e possui caráter experimental.

A API e a arquitetura ainda podem sofrer alterações significativas conforme novos recursos sejam implementados e utilizados em projetos reais.

A evolução do projeto será guiada principalmente por duas necessidades:

1. 📚 conceitos que contribuam para o aprendizado sobre desenvolvimento de bibliotecas frontend;
2. 🛠️ funcionalidades que sejam realmente úteis em meus projetos pessoais.

## 📦 Dependências

Este projeto utiliza:

- **JavaScript** — linguagem principal da biblioteca.
- **Bootstrap** — utilizado para estilos e componentes visuais.
- **Bootstrap Icons** — utilizado para ícones.

Bootstrap e Bootstrap Icons são distribuídos sob a licença MIT.

> 💡 **Observação:** a biblioteca oferece componentes **acoplados e desacoplados do Bootstrap**, permitindo tanto o uso de componentes baseados em seus recursos quanto a criação de interfaces independentes do Bootstrap.
